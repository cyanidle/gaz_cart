# Direct-voltage hold — the periodic stutter.
# Q10 is fully reachable only with at least ~22.3 V on the rail; lower rails
# clamp the applied q-voltage to their live modulation ceiling.
#
# Holds an open-loop voltage (Q, no speed loop at all) and reports the counters
# and the per-phase loop timing before and after. The reported stutter is very
# regular on direct voltage, about once every five seconds, which is the same
# rate the `slow=` counter shows for control periods over 2 ms — so this run is
# there to catch one and to show which phase of the app loop absorbed it:
#
#   `K5 ph pid=.. update=.. poll=.. persist=.. cyphal=..` (worst since boot)
#   vs `K4 loop slow=.. max_us=.. heap=.. heap_us=..`
#
#   python3 debug/bench.py script debug/bench_voltage_hold.txt
#
