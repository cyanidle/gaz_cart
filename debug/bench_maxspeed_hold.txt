# Full-scale hold, both directions — the stutter hunt.
#
# Holds the drive at its commanded maximum (normalized 1.0 = the module's full
# scale, `G16`) in each direction with the loop trace armed, and reports the
# counters before and after each hold. The stutter is more reliable the faster
# the wheel turns, so this is the run to graph:
#
#   python3 debug/bench.py script debug/bench_maxspeed_hold.txt
#
# Then read `K`: one counter per mechanism that can stop the drive or take
# authority from a regulator. The counter that moved between two `K` dumps names
# the mechanism, and an armed trace (`W1`) dumps the ~50 ms of loop history that
# led into the next snap / supply derate / stall / driver fault on its own.
#
# Wheel must be free. Never against a powered cart.
